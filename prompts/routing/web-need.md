# Web need

Decide whether an accurate answer needs current public information.

Use `yes` when the answer depends on what is true now or on a relative time period that moves with the present.

Use `no` for timeless knowledge, fixed historical questions, supplied text or code, writing, summarization, and project content.

Use `unknown` only when the request lacks enough context.

Return only the JSON required by the schema. Do not answer the request.
